# 四层面部解剖结构

当前 `Facetest` 场景已经配置为以下单向机械链：

`Anatomy Skull Layer + Anatomy Jaw Layer -> Anatomy Muscle Layer -> Anatomy Fat Layer -> Deformable Double-Sided Image（皮肤）`

每一段只驱动紧邻的上一层，骨骼不会再越过肌肉、脂肪直接修改皮肤。这样可以给每一层设置不同的响应强度、最大位移和平滑程度。

## 双骨骼层与下颚附着

头骨层和下颚层使用同尺寸、同变换的 `头骨.PNG` 与 `下颚.PNG`，直接叠放而不做二次缩放。Play Mode 中可用右键沿下颚自身纵轴拖动 `Anatomy Jaw Layer`（左键仍留给肌肉和切割工具）；姿态变化通过预绑定的下颚骨性外缘传给肌肉，再沿 `Muscle -> Fat -> Skin` 向外传播。削切下颚外缘时仍会依据保留下来的新骨缘更新肌肉轮廓。

`BoneSkinCoupler2D` 的 `Mandible Edge Attachment` 使用下颚 UV 椭圆排除区屏蔽牙齿和牙龈。排除区内部权重严格为零，外侧用 `Oral Exclusion Feather` 平滑过渡，因此牙齿、牙龈不会拖拽肌肉，下颚体、下颚角及升支附近仍能吸附并向下拉伸软组织。

下唇使用独立的 `Lower-Lip Follow` 权重区跟随下颚姿态。权重以编辑器中已有的嘴部切口曲线为严格分界：曲线上方的上唇区域被显式锁定为零，曲线下方第一排顶点立即获得 `Lower Lip Initial Follow` 起始权重，然后再按深度平滑增强。这可防止牙齿已经张开但两侧嘴唇边缘仍黏连。右键下移下颚时会形成轻微开口，而不是整张嘴一起平移。该权重不会重新启用牙齿或牙龈骨缘作为锚点。`Chin Cut Influence` 则给颏骨配置独立椭圆权重，削切下巴中央骨缘后会像削切下颌角一样改变邻近肌肉、脂肪和皮肤轮廓。

## 运行时操作

- `1`：直接拖拽肌肉层。肌肉顶点变化会依次传给脂肪和皮肤。
- `2` / `3` / `4`：仍由肌肉层的 `DeformableImageInteractor` 接收。
- `5`：开启或关闭骨骼闭合削切。成功削切后按骨骼、肌肉、脂肪、皮肤的顺序传播。
- `R`：肌肉回到当前骨骼约束形状，脂肪和皮肤随链条一起回位。

皮肤与脂肪对象上的直接交互器已停用，避免四层重叠时多个对象同时抢占同一次鼠标拖拽。

## 组件职责

- `BoneSkinCoupler2D`：保留兼容名称，目前挂在肌肉层上，负责骨骼到肌肉。
- `SoftTissueLayerCoupler2D`：负责任意两个相邻软组织层之间的变形传递。
- 脂肪层上的连接：`Muscle -> Fat`。
- 皮肤层上的连接：`Fat -> Skin`。

软组织连接按素材 UV 建立对应关系，所以相邻层可以使用不同细分数；细分完全相同时会自动采用一对一快速路径。平滑使用目标层当前仍然完整的三角形邻接关系，不会跨越已经切开的缝隙传播。

## 在其他场景中搭建

确保场景中已有一个皮肤 `DeformableImageMesh` 和一个 `AnatomyBoneMesh`，然后执行：

`GameObject > 2D Object > Build Four-Layer Anatomy Stack`

工具会创建或更新脂肪层和肌肉层，设置渲染顺序，并将输入自动路由到肌肉层。当前项目的脂肪与肌肉素材路径由该工具直接复用。

## 眼睛和嘴部的三层预切口

皮肤对象上的 `FacialFeaturePrecut2D` 管理左眼、右眼、嘴巴三条曲线。曲线以皮肤 UV 为唯一基准，编辑器烘焙时把同一组路径同时提交给三层：

1. 三条曲线切开肌肉层。
2. 同样三条曲线切开脂肪层。
3. 同样三条曲线切开皮肤层。

骨骼层不会被这组三条曲线切开。因为三个软组织层使用同一组归一化路径，切口在层间保持垂直对齐；每次拓扑改变后，相邻软组织绑定会自动刷新，因此变形平滑不会跨越切口。

三条曲线已经依据当前皮肤纹理的眼缝和唇缝像素位置校准，并在编辑器阶段序列化到场景中。进入 Play Mode 后不会运行关键点识别或等待检测，只读取现成曲线执行切割。默认 `Cut Width = 0.005`，在高度 5、1254 像素的现有素材上约为一个像素宽，是兼顾可靠物理断开与视觉极细的设置。

在 Scene 视图选中皮肤对象后，会显示三种颜色的曲线和控制点。拖动控制点即可在游戏外修改开口端点和具体曲率。`Pre-Generate / Reset Three Curves` 会恢复针对当前皮肤纹理校准过的曲线。物理切割和三角化只在编辑器烘焙时执行；Play Mode 只加载结果。

曲线预览只在选中 `FacialFeaturePrecut2D` 对象进行编辑时显示，避免平时持续重绘 Scene 视图。方形手柄表示开口端点，圆点表示中间曲率控制点，虚线是控制折线，带黑色描边的实线就是最终会执行切割的平滑曲线。烘焙后的真实开口不会显示红色切割边界。

编辑器烘焙时三条曲线按层批量提交：每一层只执行一次拓扑重建，而不是每条曲线各重建一次。三层总重建次数由 9 次降为 3 次；三条切口仍分别登记为独立机械屏障。这些耗时只发生在点击烘焙时，不会发生在 Play Mode 启动阶段。

最终确定曲线后，在皮肤对象的 `FacialFeaturePrecut2D` Inspector 点击 `Bake Final Topology Into All 3 Layers`。编辑器会执行一次布尔切割和三角化；皮肤保存唯一一份归一化拓扑模板，脂肪和肌肉引用该模板并在运行时各自建立独立网格。之后 Play Mode 直接加载烘焙数据，不再执行运行时切割。Inspector 显示 `BAKED` 即表示生效；再次拖动曲线会自动清除旧烘焙数据，修改完成后重新点击烘焙即可。此流程不会创建、删除或替换场景 GameObject。

## 运行时逐层切割

按 `4` 进入切割工具后，刀具会按光标位置从外向内选择第一个仍然完整的组织层：`Skin -> Fat -> Muscle`。皮肤在该位置仍有可见实体时只能切皮肤；皮肤形成真实开口或切除一块后，才允许切下面的脂肪；脂肪也打开后才会切到肌肉。一次鼠标拖动会锁定一个目标层，不会在刀路中途跳到下层。拖拽、膨胀和收缩工具仍由肌肉层驱动，并继续通过 `Muscle -> Fat -> Skin` 耦合链影响外层。

## 表情预烘焙

肌肉层的 `MuscleExpressionController2D` 保存编辑器预生成的五官顶点偏移。现有五个独立、可叠加的表情通道：`F2` 睁眼、`F3` 微笑、`F4` 悲伤、`F5` 愤怒、`F6` 痛苦；另有五个互斥的高权重说话口型：`Z` 收拢 U、`X` 中等露齿、`C` 窄露齿 E、`V` 大张口 Ah、`B` 圆形 O。再次按当前口型键可关闭它，`F1` 会把表情和口型全部恢复到中性状态。睁眼只把左右眼切口上方的上眼皮肌肉向上抬升，眼角保持锚定、下眼皮不移动。微笑会沿嘴巴基础曲线抬高并外扩嘴角，同时平滑带动口周。悲伤、愤怒和痛苦都是覆盖眉、眼周、鼻、面颊、嘴角及下巴的全脸肌肉权重场。同一顶点可以同时收到口型、眼睛、微笑和情绪通道的位移，全部偏移先在肌肉层相加，再由 `Muscle -> Fat -> Skin` 传递到皮肤。皮肤始终使用原始贴图，不会切换成参考图片；抬起后显示的是场景中已有的眼球模型。

选中 `Anatomy Muscle Layer` 后，Scene 视图会显示灰色的中性切口曲线、绿色和橙色的左右眼目标上眼睑曲线，以及紫色的微笑目标曲线。拖动彩色控制点即可分别调整眼角、眼睑峰值、嘴角高度、嘴巴宽度和整体弧度。Inspector 的 `Scene Muscle Channel` 可在 Smile、Sadness、Anger、Pain 和五个 Speech 通道间切换，只显示当前通道的高对比度肌肉区，避免多组椭圆互相遮挡。每个 `Speech Mouth Pose` 都可精确修改 `Jaw Drop Uv`、默认权重以及各口周影响区；修改会立即重新烘焙。`Reset All Smooth Target Curves` 可恢复全部默认目标，`Rebake All Facial Expression Poses` 可在修改基础切口后手动重建。

每个表情通道由多组可重叠的椭圆肌肉权重区组成。Scene 视图使用黑色描边和不透明高饱和颜色：通道色方块移动中心，两个青色圆点调整 X/Y 半径，黄色球形点调整牵拉方向和距离。Inspector 中对应的 Weight Field 可输入精确数值修改每区的中心、XY 半径、位移和强度。说话口型把已经预设的嘴部切口当作上下唇严格分界，Upper 区不会拉动下唇，Lower/Chin 区也不会跨线拉动上唇；需要露齿的口型还会按 `Jaw Drop Uv` 平滑移动 `Anatomy Jaw Layer`，同时保留下颚到肌肉的吸附传递。运行时可调用 `SetEyeWeight`、`SetSmileWeight`、`SetSadnessWeight`、`SetAngerWeight`、`SetPainWeight`、`SetSpeechPose(index, weight)` 与 `ClearSpeechPose()`；所有非互斥通道和同一通道内重叠区域都逐顶点相加。

`Nose Shape Preservation` 会把鼻部保护区内的差异形变平滑收敛为共同位移，使鼻梁、鼻尖和鼻翼仍可随整张脸移动，但基本保持原有宽度与长度。`Center Uv` 和 `Radius Uv` 控制保护区，`Nose Shape Protection` 控制刚性保持强度；鼻周皱褶与鼻唇沟仍由保护区软边界外的肌肉区产生。
