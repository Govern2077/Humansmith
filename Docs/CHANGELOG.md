## 2026-11-19｜手动拖拽卡顿与方向一致性

- 对侧睑缘仅在切口两端各 8% 内保留快速衰减的微量跟随，眼角基础权重降至 0.05。双眼保存网格及 Unity 回归通过。
- 拉长对侧睑缘由中段到眼角的跟随过渡，眼角基础权重由 0.30 调到 0.45，切口中央仍能分离。双眼保存网格的位移采样与 Unity 回归通过。
- 修复眼睑切口拖拽粘连。按实际眼缝分开上下睑缘权重，眼角平滑跟随，双眼保存网格 60 组对照与最大笔刷半径回归通过。
- 手动拖拽单次最大位移减半，默认普通皮肤由笔刷半径的 0.32 倍降到 0.16 倍，切口附近的三维上限由 0.6 倍降到 0.3 倍。保存网格与 GPU 回归通过。
- 后续修正苹果肌抓取。按实际深度拾取可见表面，按原始材质位置计算权重和限位，切口旁细面片不再压缩整笔行程。
- 操作面板和 F8 可开关蓝红权重图。空闲显示面部部位权重，按住显示实际笔刷权重与位移上限。用保存的 Facetest 网格验证两处苹果肌和鼻尖在压力测试前后均有约 0.24 的行程。
- 普通手动拖拽每笔使用各方向共用的安全上限，细长切口三角形的权重在手势开始时局部平滑。按住期间每帧只计算一次候选，鼠标停住时跳过更新。
- 手动拖拽的额外解剖减幅集中在眼角和嘴角。拖拽使用增量位移，避免覆盖表情或器械写入的姿态。下眼睑原型暂时默认停用。
- 三层联动复用大数组并加速反向 UV 匹配，空闲器械跳过约束计算。八方向、切口旁普通抓取、多层与 GPU 回归通过。

## 2026-11-19｜手动拖拽纵深与正背面重叠

- 下眼睑定向翻折原型支持在真实眼部切口下侧向下拉，越贴近睑缘越容易触发。左右眼阈值独立可调，眼角翻折幅度逐渐减弱。Unity 与 GPU 验证确认下睑真实翻面并可见背面。
- 开口拖拽上限从 1.2 倍刷子半径减至 0.6 倍，包含基础纵深的三维总位移。
- 按用户反馈撤回新增的按切口距离自动翻卷；眼角弱权重、外缘固定、多层联动及普通拖拽恢复翻卷实验前的响应。
- 基础拖拽纵深朝向相机，当前 Facetest 对应世界 Y 轴；基础比例 12%、上限 0.08 个局部单位，支持回弹／取消恢复。
- 回退后无额外旋转项、减半上限、GPU 渲染和既有回归检查通过，当前场景手感待复测。
- 主渲染改用严格深度测试，避免等深度、后绘制的背面覆盖正面；保留确实更近的背面、透明切口和开口翻皮能力。
- RTX 5070 Ti／D3D11 实际 GPU 对比复现旧版错误并验证修复，三层重叠、独立翻面、近处背面及透明覆盖测试通过；几何、切割、拖拽和多层联动回归通过。当前用户场景视觉复测待进行。

- Esc、换工具或禁用脚本会取消未提交预览；已有切口保留，后续笔划无预览残影。
- 撤回本轮中间尝试的实时增量网格结算及绑定优化。最终预览只更新新增路径的局部像素。

## 2026-11-12｜器械原型、操作面板与软组织联动

- 新增皮钩、可留置牵开器、局部剥离和两点缝合，提供简单器械／缝线显示及移除、收紧、重置控制。
- 工具改为面板点击选择，移除数字键开启；骨骼切割可分别选择颅骨或下颌骨。
- 修复皮肤、肌肉面板和鼠标输入重复；只绘制一个面板并显式选择操作层。
- 固定原始皮肤外轮廓，保留实际切口附近及独立碎片的活动能力。
- 眼口保持可拉伸与反复调整，附近响应约为原强度的 70%，单次大幅操作减幅；不保留累计位移预算或额外角点锁定。
- 新增手动软组织双向位移传递，恢复皮肤带动脂肪、肌肉；保留局部剥离、外缘锚定、不同网格与切口拓扑适配。
- 修复器械脚本的非法 GUID，避免 Unity 忽略源码并报 CS0246。
