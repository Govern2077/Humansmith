# 开发版本记录

## 2026-11-12｜器械原型、操作面板与软组织联动

- 新增皮钩、可留置牵开器、局部剥离和两点缝合，提供简单器械／缝线显示及移除、收紧、重置控制。
- 工具改为面板点击选择，移除数字键开启；骨骼切割可分别选择颅骨或下颌骨。
- 修复皮肤、肌肉面板和鼠标输入重复；只绘制一个面板并显式选择操作层。
- 固定原始皮肤外轮廓，保留实际切口附近及独立碎片的活动能力。
- 眼口保持可拉伸与反复调整，附近响应约为原强度的 70%，单次大幅操作减幅；不保留累计位移预算或额外角点锁定。
- 新增手动软组织双向位移传递，恢复皮肤带动脂肪、肌肉；保留局部剥离、外缘锚定、不同网格与切口拓扑适配。
- 修复器械脚本的非法 GUID，避免 Unity 忽略源码并报 CS0246。

验证：独立 Unity 2022.3.8f1c1 批处理通过三层双向传递、100 帧无漂移、回弹恢复、局部剥离、不同网格和物理切口、器械、眼口响应、单面板与原始外轮廓回归。原始外轮廓及皱纹 PowerShell 检查通过。当前用户 Facetest 窗口的视觉复测未执行。
