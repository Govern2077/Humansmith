项目：Humansmith。日期使用北京时间；按本对话实际发生顺序记录。

## 用户反馈与目标

用户先讨论真实整形器械的游戏化，再要求先做简单操作与效果；随后要求为数字键操作增加 UI 面板，不再通过数字按键开启工具。

## 第一阶段：器械原型

- 新增皮钩、留置牵开器、局部剥离和两点缝合，运行时挂到现有皮肤操作组件上。
- 皮钩松开后回弹；牵开器可留置；缝合两点后用滑杆调节最后一针；剥离局部减弱 SoftTissueLayerCoupler2D 的联动并抬起表面。
- 使用简化 LineRenderer 显示器械和缝线。约束每帧先扣除上帧贡献，避免持续叠加位移。沿用原始外轮廓锚点，网格／静止形状重建后清除失效约束。
- 初版使用数字键和可点击列表。运行脚本与验证脚本分别编译通过；独立编译验证脚本时发现同时引用 UnityEditor.dll 与 UnityEditor.CoreModule.dll 的重复类型，移除重复引用后通过。这是验证命令配置问题。
- 已编写 Unity 验证入口 Tools/Face/Validate Surgical Instruments，覆盖切口访问、留置漂移、缝合、层间释放和重置。用户两次按 Esc 停止电脑操作，未完成 Unity 交互复测；不得把已编译的验证脚本记为已执行通过。

## 第二阶段：鼠标工具面板

- 在左侧“操作工具”页集中显示拖拽、膨胀、挤压、皮肤切割、皮钩、牵开器、剥离器、缝合按钮，移除按钮上的数字前缀。
- 删除皮肤工具的数字键判断；删除骨骼切割的数字键快捷字段与判断，同时更新场景内旧字段和“Press 5”提示。
- 骨骼工具在同一面板分别显示颅骨／下颌骨，点击激活，再次点击关闭；一次只激活一个骨骼对象。点击皮肤工具会退出骨骼切割。
- 修复骨骼模式下原工具面板隐藏、无法用鼠标返回的问题；独立骨骼场景保留可点击的备用面板。
- 添加“取消当前操作”“重置皮肤与器械”按钮；保留 R / Esc 作为非数字辅助键。切换时清理未完成输入，已留置的器械按原规则保留。
- 骨骼切割增加侧边栏命中排除，点击面板不会同时在骨骼上开始画线；皱纹帮助文字同步改为点击“挤压”。
