# 2026-11-12｜原始皮肤外轮廓固定

项目：Humansmith。按北京时间记录；此进程发生在同日器械原型与工具面板迭代之前，本次补齐归档。

## 用户反馈与原图

用户反馈切口处可以大幅拉伸，但皮肤表面的原始外边缘不应被拖动拉变形。

原始截图：同目录 `2026-11-12-original-outline-feedback.png`，从本机可读取的当前对话原始附件恢复，用于记录修复前的皮肤外缘问题。

## 原因与修复

- 原抓取判断把原始可见外轮廓和切口边缘都归为允许大幅牵引、翻起的边缘。
- 从原始贴图 alpha 提取与画布外部连通的透明区域，标记原始外轮廓；内部封闭孔洞和后续切口不作为原始外缘。
- 固定支撑轮廓的网格三角形顶点，而不是仅固定矩形图片边缘，确保轮廓穿过三角形内部时也不会被拉走。
- 贴图不可读取时使用 Sprite 原始几何轮廓回退。按原始网格／拓扑缓存，切割和重建后重新计算。
- 拖拽、膨胀、挤压时保留这些顶点的操作前位置，适应已拟合或有深度的当前姿态。
- 原始轮廓与切口抓取权限分开；实际切口附近仍允许大幅牵引。独立切下的碎片保留原有布料运动能力。

## 验证过程

- PowerShell 原始轮廓检查 13 项通过，覆盖不贴画布边界的轮廓、内部孔洞、跨轮廓三角形、不受新切口影响、完全不透明图像及单像素输入。
- 初始 Unity 测试夹具的 0.08 切口宽度在低分辨率测试图上过窄，切割未命中；调整为超过一像素的 0.24 后通过。
- Unity 验证报告确认拖拽／膨胀／挤压在物理切割前后均保持外轮廓顶点，内部顶点仍可移动，并保留操作前姿态。
- 后续多层 UI 和器械迭代的独立 Unity 批处理再次运行该项，结果 PASS。
- 同日眼口限制经历了独立设计迭代：最终撤回累计位移与角点锁定，改为降低单次拉伸强度；该回退没有撤销原始外轮廓固定。

## 代码与复现入口

- `OriginalOutlineMath.cs`：原始 alpha 外边缘与积分图查询。
- `DeformableImageMesh.CopyOriginalOutlineAnchors()`：轮廓支撑顶点掩码。
- `DeformableImageInteractor`：操作时保留锚点位置。
- `Tools/Face/Validate Original Outline`：Unity 回归入口。
- `Tests/OriginalOutlineChecks.ps1`：独立算法检查。
